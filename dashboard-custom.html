FAQ

Questions fréquentes.

Je n'ai pas Power BI, comment ça marche ?
Power BI Desktop est gratuit (Windows). Pour publier en ligne (partager avec votre équipe) il faut une licence Power BI Pro à 14€/mois/utilisateur. Je vous accompagne dans le setup.
Mes données sont sensibles. Sécurité ?
Je travaille uniquement sur vos données via accès lecture seule. Je peux signer un NDA. Le dashboard final tourne chez vous (Power BI Desktop) ou sur votre tenant Power BI Service — je n'ai pas d'accès permanent.
Mes données viennent de plusieurs outils. Possible ?
Oui. Power BI peut se connecter à : Stripe, Supabase/PostgreSQL/MySQL, Google Sheets, Notion, Airtable, Excel, REST API custom, etc. Je gère l'intégration multi-sources sans surcoût (forfait Pro/Enterprise).
Le forfait inclut-il la formation de mon équipe ?
Une session de 1h (Pro) ou 2h (Enterprise) pour vous + vos collaborateurs. J'enregistre la session sur Loom pour rejouer plus tard. Documentation écrite des mesures DAX incluse.
Si je veux ajouter des choses plus tard ?
Avenant sur devis (TJM 500€/jour). Petites modifs (1 mesure, 1 visuel) gratuites pendant 30 jours après livraison. Refonte plus large = nouveau forfait.
Puis-je avoir un Tableau / Looker Studio à la place ?
Oui pour Looker Studio (gratuit, +0€). Pour Tableau, je connais l'outil mais Power BI reste 30% plus rapide à développer pour moi. À discuter en discovery.
